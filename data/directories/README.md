# data/directories – addressee directories for `/akce`

Static JSON used by the letter page (SPEC §9.2) to find addressees in the browser.
Everything is generated by `scripts/import-directories.mjs` from public open data;
nothing is typed in by hand. Do not edit the JSON files – re-run the importer.

## Re-running

```sh
node scripts/import-directories.mjs                    # fetch all sources, rewrite *.json + meta.json
node scripts/import-directories.mjs --only=poslanci    # one or more of: kraje,poslanci,senatori,obce,static
node scripts/import-directories.mjs --cache            # cache raw downloads in <os tmp>/obcansky-kompas-import-cache (dev)
node scripts/import-directories.mjs --write-fixtures   # also regenerate fixtures/ from the fresh data
```

Node ≥ 22, no npm dependencies (built-in `fetch` + `zlib`, own ZIP/CSV parsers).
A full run makes ~450 HTTP requests (~70 MB, mostly `ovm.json`) and takes 1–3 minutes.

If a source fails, the importer keeps the previous full import (`"status": "kept"`), or – when
there is none – copies `fixtures/<file>` into place (`"status": "fixture"`), and records the error in `meta.json`. Check `meta.json` → `files.*.status`
and `warnings` after every run.

## Files

| File | Records | Content |
| --- | --- | --- |
| `kraje.json` | 14 | kraje + krajský úřad (address, data box) |
| `poslanci.json` | 200 | current Poslanecká sněmovna members |
| `senatori.json` | 81 | current senators by senate district |
| `obce.json` | ~6 254 | municipalities → kraj, okres, senate district(s), municipal office; MČ/MO for split cities |
| `static.json` | 2 | Ministr kultury, Prezident republiky |
| `meta.json` | – | source URLs, fetch dates, counts, sizes, warnings |
| `fixtures/*.json` | few | same shapes, small subset (Praha, Brno, Ostrava, Opava, Blatec …) for tests / offline dev |

`kraj_code` everywhere is the NUTS3 code (`CZ010` Praha … `CZ080` Moravskoslezský).

### obce.json (minified, ~1.3 MB, ~230 kB gzip)

```jsonc
[{
  "kod": 582786,                 // ČSÚ/RÚIAN obec code
  "nazev": "Brno",
  "kraj_code": "CZ064",
  "okres": "Brno-město",
  "senatni_obvod": [55, 58, 59, 60],   // ALWAYS an array; >1 only for split cities
  "urad": {                      // municipal office = OVM of the obec
    "address": "Dominikánské náměstí 196/1, Brno-město, 602 00 Brno",
    "datova_schranka": "a7kbrrn",
    "nazev": "Statutární město Brno"   // OVM name as in RPP (case as published)
  },
  "casti": [{                    // only for the 8 cities split into MČ/MO
    "kod": 551082,               // ČSÚ code of the městská část / obvod
    "nazev": "Brno-Bohunice",
    "senatni_obvod": [58],
    "urad": { "address": "…", "datova_schranka": "hm2byk9", "nazev": "Městská část Brno-Bohunice" }
                                  // null for "nečleněná část města" (governed by the city itself)
  }]
}]
```

UI hint: for a single-obvod obec take `senatni_obvod[0]`; if the array has more than one
entry, ask the user for the městská část / obvod (`casti`) and use its `senatni_obvod`.
Praha 2, 4, 6, 9 and 10 are themselves split by polling district between two senate
districts (and Praha-Petrovice has conflicting sources) – their `casti[].senatni_obvod` has two values, so let the user choose.
The four vojenské újezdy are excluded because they have no municipal government and no voters.
The file stays below 3 MB; if it ever exceeds it, the importer also writes `obce/<kraj_code>.json`.

### static.json

```jsonc
{
  "ministr_kultury": {
    "adresat": "Ministr kultury", "urad": "Ministerstvo kultury", "ico": "00023671",
    "address": "…", "address_source": "<ISDS URL>",
    "address_podatelna": "Maltézské náměstí 1, 118 00 Praha 1", "address_podatelna_source": "<mk.gov.cz>",
    "datova_schranka": "8spaaur", "datova_schranka_source": "<RPP URL>",
    "email": "epodatelna@mk.gov.cz", "email_source": "<mk.gov.cz podatelna page>",
    "web_form": null, "web": "https://www.mk.gov.cz/", "notes": [],
    "osoba": {                 // current office holder (letters: name in the address, salutation by gender)
      "jmeno": "Oto", "prijmeni": "Klempíř", "titul_pred": null, "titul_za": null, "pohlavi": "M",
      "zdroj": "https://vlada.gov.cz/cz/vlada/", "zdroj_detail": "<member page>", "overeno": "2026-10-28"
    }
  },
  "prezident": { /* same shape; Kancelář prezidenta republiky */ }
}
```

`prezident.email` and `prezident.web_form` are `null`: hrad.cz returns HTTP 403 to
automated requests, so they cannot be imported. For the same reason `prezident.osoba` (name, sex)
comes from Wikidata (Q213 P35 head of state without end date, P21 sex) – the source is recorded in
`osoba.zdroj` and `notes`. Titles are `null` because these sources do not list them (never typed in). The address and data box come from ISDS/RPP.
If you need them, fill them in by hand from the hrad.cz contacts page and record the source.

## Sources

| Data | Source |
| --- | --- |
| Poslanci (members, kraj, klub, kandidátka) | PSP open data `poslanci.zip` (UNL, windows-1250) – https://www.psp.cz/sqw/hp.sqw?k=1300; current term = organ type 11 with no end date |
| Poslanci e-mail | each member's profile page `psp.cz/sqw/detail.sqw?id=<id_osoba>` (the open data have no e-mails for the current term) |
| Senátoři | https://www.senat.cz/senatori/index.php?lng=cz&par_2=2 (list) + `par_3=<id>` (profile: e-mail, titles) |
| Obce, okres, kraj, MČ/MO | volby.gov.cz – latest Poslanecká sněmovna číselníky (`cisob`, `pscoco`, `cnumnuts`) |
| Obec → senate district | volby.gov.cz senate číselníky `secoco` – for each district the newest election that contains it (currently se2026, se2024, se2022); gaps filled and cross-checked with senat.cz `o_obvodu.php?kod=<n>` ("Popis volebního obvodu") |
| Office data box, IČO, name | RPP – Seznam OVM, https://rpp-opendata.egon.gov.cz/odrpp/datovasada/ovm.json (obec = právní forma 801, Praha MČ = 811, kraj = 804; other MČ/MO are internal units of the city) |
| Office postal address | ISDS – Seznam datových schránek OVM, https://www.mojedatovaschranka.cz/sds/datafile?format=xml&service=seznam_ds_ovm |
| IČO → obec / MČ code | ARES REST `ekonomicke-subjekty/vyhledat` (batch by IČO) |
| Ministerstvo kultury e-mail | https://www.mk.gov.cz/podatelna-ministerstva-kultury-cs-2816 |
| Poslanci pohlaví | PSP `osoby.unl` column `pohlavi` |
| Senátoři pohlaví | senat.cz profile, membership roles (`<dt>` člen/členka …); fallback derived from the name |
| Ministr kultury (jméno, pohlaví) | https://vlada.gov.cz/cz/vlada/ (list of government members, office title ministr/ministryně) |
| Prezident (jméno, pohlaví) | hrad.cz if it answers; otherwise Wikidata https://www.wikidata.org/wiki/Q213 (P35, P21) |

## Known caveats (see `meta.json` → `warnings`)

- 18 senators publish no e-mail on senat.cz → `email: null` (send by post or data box via Kancelář Senátu).
- Some Praha městské části are missing from the volby senate číselníky because district boundaries changed;
  they are filled from senat.cz. Where the two sources disagree (Praha-Petrovice: volby 17, senat.cz 19)
  both districts are kept.
- A few municipal offices have their registered seat in a neighbouring municipality; those are matched by
  unique name within the RPP list (`offices_matched_by_name` in meta).
